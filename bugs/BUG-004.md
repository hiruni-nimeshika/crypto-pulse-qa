# BUG-004: Browser tab title is 'frontend' instead of the app name

- **Reported by:** Hiruni Nimeshika
- **Observed:** 17 November 2026
- **Area:** Usability / branding / SEO
- **Severity:** Low
- **Priority:** Medium
- **Status:** Open (verify)
- **Environment:** Google Chrome, Windows, https://crypto-pulse-weld.vercel.app

## Steps to reproduce
1. Open https://crypto-pulse-weld.vercel.app
2. Look at the browser tab title

## Expected result
The tab shows the app name, for example 'Crypto Pulse'.

## Actual result
The tab shows 'frontend', the default name from the Vite project template. The page title returned by the server is also 'frontend'.

## Evidence
- ![evidence](../../screenshots/BUG-004-tab-title-frontend-2026-11-17.png)

## Root cause
`<title>` in `frontend/index.html` was never changed from the template default.

## Fix
Change it to `<title>Crypto Pulse</title>` in `index.html`, and add a meta description.

## Retest
After redeploying, check that the tab reads 'Crypto Pulse'.
