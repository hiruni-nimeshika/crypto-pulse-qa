# BUG-002: No error message when prices fail to load: the spinner never stops

- **Reported by:** Hiruni Nimeshika
- **Observed:** 17 November 2026
- **Area:** Error handling
- **Severity:** High
- **Priority:** High
- **Status:** Fixed in code, live retest needed
- **Environment:** Same as BUG-001 (found while investigating it).

## Steps to reproduce
1. Make the price request fail (this happened on the live site because the back end was gone)
2. Watch the 'Market Prices' section

## Expected result
A clear error message with a way to retry, and old prices stay visible if a refresh fails.

## Actual result
The user only sees 'Loading market data...' indefinitely. In the original code the error was only written to the console, and the failure message was set in a state variable that is displayed in the alert form, not in the prices section.

## Evidence
- ![evidence](../../screenshots/BUG-001-live-site-stuck-loading-2026-11-17-0750.png)

## Root cause
`fetchPrices` caught the error but did not update the prices section, and the UI treated 'no prices' as 'still loading'.

## Fix
Added `loading` and `error` states, an error panel with a 'Try again' button, and a warning banner when a refresh fails but older prices are shown.

## Retest
In DevTools (F12) > Network, set 'Offline', reload, and confirm an error and a Try again button appear instead of a spinner. Switch back online and click Try again.
