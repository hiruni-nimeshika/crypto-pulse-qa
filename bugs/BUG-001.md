# BUG-001: Live site is stuck on 'Loading market data...' and never shows prices

- **Reported by:** Hiruni Nimeshika
- **Observed:** 17 November 2026
- **Area:** Dashboard / deployment
- **Severity:** Critical
- **Priority:** High
- **Status:** Fixed in code, live retest needed
- **Environment:** Google Chrome, Windows, https://crypto-pulse-weld.vercel.app (live). Compared with http://localhost:5173 (local).

## Steps to reproduce
1. Open https://crypto-pulse-weld.vercel.app
2. Scroll to the 'Market Prices' section
3. Wait one minute

## Expected result
Five coin cards with current prices load, 'Coins Tracked' shows 5 and 'Updated' shows a time.

## Actual result
A spinner with 'Loading market data...' stays forever. 'Updated' shows --:--:-- and 'Coins Tracked' shows 0. The same code shows all five coins on localhost:5173.

## Root cause
The deployed front end called a hosted back end (a Render.com URL) that no longer exists, so every price request failed. Locally the app used the back end running on the developer's laptop.

## Fix
Prices are now fetched directly from the CoinGecko API in the browser (`fetchPrices` in `src/App.jsx`), with a 30-second refresh. The back end is only needed for alerts.

## Retest
Open the live site after the Vercel redeploy, hard-refresh (Ctrl+Shift+R), and confirm five coins load and 'Updated' shows a time.
