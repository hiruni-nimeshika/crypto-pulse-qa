# BUG-006: Price alerts do not work on the live site, although the page advertises them

- **Reported by:** Hiruni Nimeshika
- **Observed:** 17 November 2026
- **Area:** Alerts / deployment
- **Severity:** High
- **Priority:** High
- **Status:** Open (known limitation), now shown clearly to the user
- **Environment:** Google Chrome, Windows, https://crypto-pulse-weld.vercel.app

## Steps to reproduce
1. Open the live site
2. Fill in 'Set Price Alert' with an email, a coin and a valid price
3. Click 'Set Alert'

## Expected result
The alert is saved and the user receives confirmation.

## Actual result
The alert back end is not deployed, so the request cannot succeed. The page still promises 'Instant email notifications' and 'Free alerts'. In the earlier code the failure message appeared only in the alert form and was generic.

## Evidence
- Code review: the alert request uses `API_URL`, which previously pointed to a dead host.

## Root cause
The Express and SQLite back end exists only on the developer's machine (alerts also need a host with persistent storage and an email service).

## Fix
Short term: the app now shows a clear message when the back end is unavailable. Long term: deploy the back end (Render or Railway) with a persistent database and set `VITE_API_URL` in Vercel.

## Retest
On the live site, submit a valid alert and confirm the message says alerts need the back end. After deploying the back end, confirm the alert is saved and survives a restart.
